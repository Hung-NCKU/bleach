# 鬼道訓練班（Kidō Training Class）

仿《火影忍者 終極風暴》操作的 3D 對戰格鬥遊戲，以 **Unity** 製作。
控制器只負責基本動作；**所有鬼道都只能用語音詠唱施放**：唸得越準、越完整，威力越高。

- 角色：32 名，24 名已接入下載的骨架模型與貼圖，8 名仍為暫用造型；技能仍共用近戰與鬼道
- 場景：瀞靈廷、虛圈、空座町、靈王宮、地獄門前（研究版初版佈局）
- 模式：主線模式（六篇章、21 場改編對戰、漸進難度與本機存檔）、對戰模式（vs CPU，三種難度）、鬼道練習（木樁＋無限靈壓，R 重置）
- 鬼道：收錄中文維基百科「鬼道」條目的全部招式（破道、縛道、其他，共 53 招）＋語音測試用的「測試」

> 完整的製作流程（架構、各模組實作、語音比對演算法、驗證數據）請見 **[docs/製作流程.md](docs/製作流程.md)**，可作為教學研究參考。

素材的實際使用情況與逐項來源，見 [素材來源紀錄](ASSET_CREDITS.md)及[角色模型清單](docs/asset-sources/roster-models.json)。角色資產保留來源署名，沒有宣稱是本專案原創或 CC0。

目前為下載模型整合與關卡初版，**尚未達到《BLEACH 魂魄覺醒》的美術等級**。模型主要來自 PSP／Wii 作品，不能等同現代主機遊戲品質。尚未實作原作角色專屬能力、變身、過場與完整劇情演出。

製作步驟、角色與場景預覽、主線關卡表、效能改善與驗證方式見 [重製與主線製作紀錄](docs/art-remake/README.md)。

「測試」招式僅供設定頁與練習模式；主線與正式對戰排除此免費招式。

## 開啟方式

1. 用 Unity Hub「Add project from disk」加入這個資料夾（Unity 2022.3 LTS 或 Unity 6）。
2. 按 **Play**，遊戲會直接進入 **主線模式**（不需要設定場景）。
3. 選擇篇章與關卡，按「開始關卡」或 Enter。未解鎖關卡可預覽，過關依序解鎖並自動存檔。
4. 本機有 Windows 版本時，雙擊根目錄 `START-STORY.cmd`（執行 `Build/StoryAssets/KidoTraining.exe`）。

新版首頁下方會顯示「主線・下載角色整合版 2026.10.18」。若看不到，請確認已更新 main；舊分支／舊 exe 不會自動更新。

直接查看下載模型：雙擊 `START-YORUICHI.cmd`，或選主線選單左下「體驗下載角色：夜一」。夜一已替換為網路下載的模型，保留原始貼圖與骨架，來源標示 CC BY 4.0；其他角色尚未全部替換。

## 語音辨識

使用 **Vosk 離線語音辨識**（中文模型已內附於 `Assets/StreamingAssets`），不需要網路，也不依賴 Windows 語音設定。
比對以**拼音（讀音）**為準，辨識成同音字也能得分；台灣口音常見的 zh/z、ch/c、sh/s、n/l、in/ing、en/eng 也有部分分數。

**持續監聽**：戰鬥中與設定頁麥克風常開，**唸出詠唱並喊出招式名**就自動辨識、評分、發動。

- 先試：進入「設定」，直接說「**測試**」，下方會顯示聽到的文字與各鬼道的相似度。
- 戰鬥中按 **F1** 顯示／隱藏語音診斷，按住 **Tab** 看鬼道一覽。

## 操作（終極風暴式）

| 動作 | 鍵盤 | 手把 |
|---|---|---|
| 移動 | W A S D | 左搖桿 |
| 攻擊（四段連擊；空中＝下劈） | J | B |
| 跳躍／二段跳 | K 或 Space | A |
| 集中靈壓（長按） | L | Y |
| 瞬步：朝對手衝刺（消耗靈壓 12） | L → K | Y → A |
| 防禦（長按） | I | RB／LB |
| **詠唱鬼道** | **語音（持續監聽）** | **語音** |
| 暫停 | Esc | Start |

## 靈壓與評分

- 瞬步與所有鬼道都會消耗靈壓；長按集中靈壓可回復。奧義（黑棺、千手皎天汰砲、一刀火葬、五龍轉滅、卍禁太封、時間停止）需要靈壓全滿。
- **相似度**：唸出的內容有多少是對的；**完整度**：整段詠唱（含招式名）唸出了多少。音量不影響威力。
- 威力倍率 = (0.25 + 0.85 × 相似度^1.3) × (0.4 + 0.6 × 完整度)。有詠唱的鬼道只喊招式名＝**詠唱破棄**，威力 ×0.1。
- 施放時會出現**詠唱評價特效**：S／A／B／C／D（相似度 50%＋完整度 50%，詠唱破棄為 D），評價越高，角色腳下的光環越華麗。
- 詠唱中被擊中會被打斷；被縛道束縛時無法施放。

## 程式結構（`Assets/Scripts`）

| 檔案 | 內容 |
|---|---|
| `GameManager.cs` | 自動啟動、畫面流程、IMGUI 選單、戰鬥 HUD、詠唱評分特效 |
| `Battle.cs` | 一場戰鬥：判定、屏障、四獸塞門封印、反鬼相殺、雙重詠唱 |
| `Fighter.cs` | 角色狀態機：移動、連段、防禦、靈壓、受擊、各種增益 |
| `FighterModel.cs` / `FaceTex.cs` | 程序化角色模型（卡通渲染、動畫風臉部貼圖、髮束）與姿勢表 |
| `KidoEffects.cs` / `KidoEffects2.cs` | 各鬼道的特效與判定 |
| `VoiceCaster.cs` | Vosk 離線辨識（背景執行緒）、持續監聽、評分 |
| `PostFX.cs` / `HudArt.cs` / `Portraits.cs` | 後製（泛光、調色、暗角）、HUD 貼圖、角色頭像 |
| `Similarity.cs` | 詠唱正規化、拼音軟性比對（`Resources/pinyin.txt`） |
| `Spells.cs` | 鬼道資料與角色能力值 |
| `AIController.cs` | 電腦對手 |
| `Arena.cs` | 瀞靈廷／虛圈場景 |
| `CameraRig.cs` / `Particles.cs` / `Sfx.cs` / `MeshGen.cs` / `Mats.cs` | 鏡頭、粒子、合成音效、程序化網格、材質 |
