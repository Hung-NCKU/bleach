# 行動操作更新

保留現有黑崎一護模型。角色縮圖改為胸像取景，並修正附加光源未乘上角色貼圖、導致黑衣與臉部細節被白光蓋住的著色問題。

- WASD／左搖桿：依鏡頭自由移動，同時面向鎖定對手。
- I + 方向 + K（手把 RB + 左搖桿 + A）：側向或後撤閃步；動作 0.2 秒、短暫迴避 0.12 秒、冷卻 0.55 秒。空中也可使用，受擊期間不可使用。
- L + K（手把 Y + A）：消耗 12 靈壓追擊，支援持續按住靈壓再按跳躍。
- 追擊途中按 J／B：預先輸入普攻，接近後出招；超時而未接近不會自動攻擊。
- 普通跳躍與二段跳維持原操作。

參考：《NARUTO SHIPPUDEN: Ultimate Ninja STORM 4》官方 PC 操作手冊的 Chakra Load + Jump → Chakra Dash，以及官方商品頁介紹的衝刺銜接連擊。
