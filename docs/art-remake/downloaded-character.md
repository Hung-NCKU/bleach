# 真正替換下載角色模型

此次直接使用網路提供的 **Cha Yoruichi / anywhere 3D**，不是依圖片重畫的
幾何角色。保留原始 GLB、貼圖、1579 個頂點、3038 個三角形與 48 根骨骼。
來源 API 標示 CC BY 4.0，逐項資料見 `docs/asset-sources/yoruichi-model.json`。

夜一已在 `FighterModel` 中替換；載入失敗會明確報錯，不會默默退回舊幾何體。
資產透過 glTFast v5.0.4 匯入，存成 Unity prefab；原始 GLB 未修改。
現有 11 關節姿勢以原骨骼的靜止旋轉和身體座標軸適配，保留原始蒙皮。
模型、材質與貼圖為共用專案資產，退出對戰只刪除實例。

## 直接查看

- 雙擊 `D:\claude\bleach\START-YORUICHI.cmd`，直接進入夜一練習場。
- 或正常開遊戲，在主線左下按「體驗下載角色：夜一」。
- 或對戰／練習選角選四楓院夜一。
- Unity 內執行 `ImportedCharacterBuild.ValidateAndBuild` 可重建與驗證。

驗證涵蓋原始蒙皮、骨骼／手部映射、攻擊姿勢的頂點變化、有效範圍、
實例刪除後共用網格仍存在，以及 Windows 對戰中載入原模型與貼圖。
實際使用的仍是共用戰鬥技能，尚未完成夜一專屬招式或動作庫。
